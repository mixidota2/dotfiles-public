# 設計と実装の検証

既存リンク用のentrypoint。作業モードに応じて次を読む。

- 提案・設計review、または実装で境界を変える前: [design-validation.md](design-validation.md)。候補を反証し、`Revise`を修正して同じrubricで再評価する。
- 実装後の差分・test・品質check: [implementation-validation.md](implementation-validation.md)。設計・reviewのみなら実装時の検証計画として使い、編集や実行済みの主張をしない。

実装testは設計の反証を、設計self-reviewは実装testを代替しない。
